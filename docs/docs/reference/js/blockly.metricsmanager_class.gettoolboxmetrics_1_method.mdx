## MetricsManager.getToolboxMetrics() method

Gets the width, height and position of the toolbox on the workspace in pixel coordinates. Returns 0 for the width and height if the workspace has a simple toolbox instead of a category toolbox. To get the width and height of a simple toolbox, see [MetricsManager.getFlyoutMetrics()](/reference/js/blockly.metricsmanager_class.getflyoutmetrics_1_method).

**Signature:**

```typescript
getToolboxMetrics(): ToolboxMetrics;
```
